# Sample data

Fictional data for demos and tests. Names, handles, phone numbers and reference numbers are made up.

- `chats_hinglish.json`: customer chats, including the cases that must go to the owner.
- `catalog_sample.json`: items with the three availability types and price rules.
- `bank_statement_sample.csv`: a statement to match payments against. Try a screenshot that reuses reference `412345678901` for a second order to see the duplicate check fire.
